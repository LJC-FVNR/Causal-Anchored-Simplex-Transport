# Results Artifacts

This directory contains submitted-result tables and figures copied from the
release preparation artifacts.

- `tables/*.tex`: submitted table sources.
- `figures/*.pdf`: submitted figure files.
- `metrics/`: reserved for CSV/JSON outputs from fresh runs.

The static files are included for inspection and paper traceability. Fresh run
artifacts should be written under `outputs/` first, then copied into
`results/metrics/` only after aggregation and validation.
